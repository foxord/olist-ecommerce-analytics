## Что учесть перед объединением

- Позиции и платежи суммируют по заказу отдельно. Прямое соединение этих двух таблиц по заказу даёт все комбинации строк.
- Для последних отзывов используются время ответа, время создания, идентификатор отзыва и технический номер строки.
- У 610 товаров отсутствует категория. Ещё у 13 товаров с известной категорией отсутствует английский перевод.
- Для географического анализа по штатам достаточно адреса покупателя в customers. При добавлении координат сначала приводят справочник к одной строке на почтовый префикс.
