# Этапы проекта

| Этап | Результат | Как проверить |
|---|---|---|
| 0–1 · Окружение и знакомство | [Первый ноутбук](../notebooks/01_exploration.ipynb) | Объяснить разницу между order_id, customer_id и customer_unique_id. |
| 2 · База | [Загрузка](../sql/02_load.py) | Сравнить две колонки количества строк для девяти таблиц. |
| 3 · Качество | [Аудит](data_quality_report.md) | Найти пример завышенной суммы после соединения. |
| 4 · Метрики | [Бизнес-выводы](sql_findings.md) | Запустить сверку товарного оборота. |
| 5–6 · Python и статистика | [EDA](../notebooks/02_eda.ipynb) и [гипотезы](../notebooks/03_hypotheses.ipynb) | Повторить расчёт разницы оценок и объяснить интервал. |
| 7 · Отчёт | [Дашборд](../dashboard/) | Сменить штат на всех трёх вкладках и сбросить фильтр. |
| 8 · Требования | [Истории](user_stories.md), [UML](use_cases.png), [BPMN](order_process.bpmn) | Проследить путь заказа от создания до доставки. |
| 9 · Портфолио | [Ответы к собеседованию](interview.md) | Воспроизвести один SQL-запрос и объяснить ограничения вывода. |

История коммитов фиксирует публикацию этапов. Этот трекер хранится в самом репозитории.
