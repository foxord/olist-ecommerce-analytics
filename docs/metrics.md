# Как считаются показатели

Слово «продажа» здесь означает заказ в конечном статусе `delivered`. Месяц продажи определяется моментом покупки. Денежная единица — бразильский реал (BRL, R$).

| Показатель | Расчёт | Наблюдение и знаменатель |
|---|---|---|
| Товарный оборот (GMV, колонка `revenue`) | Сумма `order_items.price` по доставленным заказам | Одна строка позиции соответствует одной проданной единице. Доставка, комиссии и маржа в GMV не входят. Выручка самой площадки неизвестна. |
| Доставленные заказы | Число уникальных `order_id` со статусом `delivered` | В витрине одна строка на заказ, поэтому достаточно `COUNT(*)` после отбора статуса. |
| Средний чек (AOV) | GMV / число доставленных заказов | Чек содержит только товары. При нуле заказов показатель не определён. |
| Покупатели | Число уникальных `customer_unique_id` в доставленных заказах | Один покупатель может встречаться в нескольких месяцах, поэтому месячные количества нельзя складывать как уникальных за весь период. |
| Доля доставленных | 100 × число заказов `delivered` / число заказов всех статусов | Для месяца отбираем все заказы, оформленные в этом месяце, и смотрим их статус в выгрузке. |
| Срок доставки | Дата получения минус дата покупки | Целые календарные дни среди доставленных заказов с известной датой получения. |
| Доля опозданий | 100 × число доставленных после обещанной даты / число доставленных с обеими датами | Заказ, полученный в обещанный день, считается своевременным независимо от времени. |
| Средняя оценка | Среднее `review_score` по одному последнему отзыву на доставленный заказ | Для сравнения со сроком также требуется известная дата доставки. Пропущенная оценка не заменяется нулём. |
| Доля по способу оплаты | Число платёжных строк способа / число всех платёжных строк доставленных заказов | Дополнительно считаем долю суммы оплат. Для AOV по способу берём целый заказ один раз на способ, поэтому смешанная оплата может попасть в несколько групп. |
| Повторный покупатель | Покупатель с двумя и более разными доставленными заказами | Повторная покупка может произойти и в том же месяце. |
| Удержание в месяц N | Уникальные активные покупатели когорты в конкретный календарный месяц N / размер когорты | Когорта — месяц первой наблюдаемой доставленной покупки. Месяц 0 равен 100%. Периоды после конца наблюдения не имеют значения. |

Для категорий GMV распределяется по фактическим позициям. Для географии используется адрес покупателя из заказа. Последняя оценка выбирается по времени ответа, затем по времени создания, идентификатору отзыва и номеру исходной строки. Эти правила реализованы в [витрине заказов](../sql/04_order_mart.sql).

Для RFM точка отсчёта — **30 августа 2018 года**, следующий день после последней покупки среди доставленных заказов. R — календарные дни с последней покупки, F — число доставленных заказов, M — накопленный товарный оборот клиента в BRL. Граница 90 дней задаёт понятное окно для кампании. Поскольку у большинства покупателей F = 1, сегменты выделяем по факту повтора и R, а денежный вклад каждого сегмента измеряем через M. Названия «ушедшие» и «давние» обозначают отсутствие покупки в этом окне. По данным нельзя установить, что клиент ушёл навсегда.
